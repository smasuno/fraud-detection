# Fraud Detection Portfolio Projects

I am currently applying to a few fraud detection data science roles, so I decided to put together some sample projects.

From my experience working on fraud detection ML validation projects for Synchrony Bank early in my career, I was aware of the prevalence of XGBoost for fraud scoring at the transaction level. Fraud detection is a challenging in machine learning for multiple reasons, but the defining characteristics include the class-imbalanceness of the problem and the fact that true-labels are often unobtainable. 

In addition, my curiosity in Graph Neural Networks was piqued by a webinar I attended by Kumo.AI and Professor Jure Leskovec on the application of GNNs for identifying fraud rings. I also took the XCS224W: Machine Learning with Graphs course taught by Prof. Leskovec two years ago, but never had the chance to properly absorb the material -- so this project was a great opportunity for me to recap the materials.
